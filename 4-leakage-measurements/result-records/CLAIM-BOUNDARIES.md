## Recommendation supported so far

Use private immutable serving for the admitted pinned package catalog, with
publisher hashes and dependency/function checks. For the tested generic
cached-failure mechanism, partition state using a trusted identity key and
measure the extra origin work. Choose each control for the specific observation
interface it addresses.

P2b now shows that the tested per-tenant gateway topology and minimum-header
floor leave activity discrimination. Padding adds 9.064939 ms to the pooled
probe median. P8 separately verifies that private cgroups do not conceal
the live aggregate CPU input; a static bind removes that particular feature.
Utility evidence covers the tested file/HTTP tasks, not legitimate telemetry
consumers or an operational replacement for all host counters.

P9's completed narrow content intervention leaves discrimination in both
active cells. Do not recommend changing only these hot-object checksums as
sufficient timing mitigation. Distinct canonical files do not show page-cache
residency or globally separate storage. The result is limited to this
single sequential lab2 run, with unchanged receiver bytes/ETag and later
own-decoder idle controls. Wider catalogs/disks and production resource
virtualization remain untested. P2b's padding result is unchanged.
