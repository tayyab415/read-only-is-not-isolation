# A result record for each tested property

[ISOLATION-RESULTS-v3.json](ISOLATION-RESULTS-v3.json) is the current working export of
completed findings, outside the paused manuscript. Each record names the
receiver's actual interface, sender action, tested configuration, outcome
type, assigned denominator, controls, utility or resource cost, exact
evidence locators and limits. Nine properties are complete. Actual native
cleanup and bounded cost reconciliation pass. Full-bundle assembly and readback
remain pending. Versions 1 and 2 remain unchanged, and version 3 preserves
all eight preceding records.

A deployer should choose a record whose property matches the intended claim.
The cached-404 record supports trusted partitioning of that application
state. The Linux record supports installations from the admitted catalog.
The HTTP association record shows why repository authorization cannot
certify all receiver observations. No record certifies whole-host isolation.

The gateway record now includes the failed 12 ms floor prediction. Native
implementation meets that minimum, but the decoder still scores 216/300.
Separate gateways score 197/300. Both retain detectable activity, and the
secondary comparisons establish no accuracy reduction. This record carries
the added latency, passing idle control and unresolved internal cause.

The counter record separates private cgroup accounting from a host-wide
input. Native counter reading scores 64/64; an actual static bind makes
the feature constant and scores 32/64. Both idle controls pass. The record
retains 736 file tasks and 1,472 trial GETs as narrow utility evidence.
Production telemetry virtualization and other observations remain untested.

The content/layout record adds P9's complete negative mitigation result:
equal/distinct scores 254/267 of 300, with both raw/corrected idle controls
passing. Native mappings verify one/two canonical identities with fixed
receiver object-15 bytes/ETag. Both tenants' object 0 change, and the rest
of the catalog and host remain shared. The record retains Fisher p=0.147027,
50/150 versus32/150 executed-trial overruns, fixed cell order and later
own-decoder idle windows. It does not establish equivalence or an internal
cause. Distinct hot-object content is insufficient for this receiver here.

Keep serving correctness in the same review. The ordinary subjects exposed
an incorrect HEAD length in the custom wrapper, despite passing pip tasks.
A future control must preserve the serving contract its clients rely on.
Installation utility and HTTP semantics need their own denominators.

Use model outcomes as search evidence. A zero attribution outcome with zero
statistics-query coverage should never override the scripted mechanism
witness. Conversely, a correct private-value reply is not enough to assign
a communication mechanism without a native witness.

These records are a proposed regression-suite output, not a deployed
configuration policy. Production effectiveness and validation after changes
remain untested. The generator reads completed aggregates and checks the
record structure and exact native cache totals. It makes no experiment,
provider or network request and preserves original sources and outputs.
Version 2 checks every prior evidence hash and the actual complete P2b/P8
primary, separate-verification, native review and chronology before adding
their records. Version 3 rechecks all preceding references and binds
P9's actual original/separate results, complete native review, prior
model publication, both idle decisions and fresh portable replay. It reads
completed aggregates, not trial observations, and runs no scientific
analysis, auditor or fitting.
