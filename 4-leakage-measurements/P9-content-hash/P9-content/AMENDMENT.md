# P9 edition 2: public response validation

Declared after the first 32 smoke trials and before any calibration, model
or held trial. The first edition and every public payload, clean seal,
native mapping, stopped status and original AttributeError remain locally
and remotely under `archive/science-v1`. No original result is replaced.

The actual worker represents response headers as pairs. Edition 1's new
content validator incorrectly expected a dictionary. It also selected
the blocked statistics URL by a package filename suffix, although that
403 response is not a successful package read. Six regressions replay
the actual original worker records, retaining missing, duplicate and
wrong ETag refusal and wrong-body refusal.

Edition 2 checks exactly the seventeen assigned plain package reads per
trial, requires one matching ETag from the actual header pairs, and keeps
the separate statistics request and its 403 denial. Raw headers and every
request still enter the original full gateway/backend/router audit.
No tolerance, route, source body, recipe, payload length, request count,
sender flag, schedule seed, calibration rule, test family, null gate or
assigned denominator changes.

Fresh smoke fixtures use `p9-s2-*`; first calibration and held fixtures
remain unused `p9-c1-*` and `p9-h1-*`. The additional native ID allowance
exists only for that fresh smoke. All four fresh cells must pass native
audit and transport before calibration. Scientific sources, the unchanged
independent arithmetic and operational/cleanup closure must freeze again
before fresh native collection. The old failed smoke does not enter fitting.
