\subsection*{4.8 A shared code without a channel: copies agree more on average, but not reliably, and mixed pairs agree too}
Covert coordination needs a channel and a shared code: agreement on what an observable change means. Sections 4.1--4.6 remove channels. Here we ask how often independently sampled agents choose the same code, and whether mixing model developers lowers that. Copies independently writing encoders and decoders were already tested by Motwani et al.\ (App.~F.1.4), and isolated same-model versus cross-model signalling by Shirnin and Kudelya (2026) on a word-description task at temperature 0. We add a factorial comparison of model pairing and task wording on a rendezvous task tied to the shared-server setting above, with exact scoring frozen before collection.

\textbf{Design.} Seven Bedrock models from six developers (GPT-6 Luna and gpt-oss-120b from OpenAI; DeepSeek v3.2; Mistral Large~3; Llama~4 Maverick; GLM~5; Qwen3 Next 80B) each wrote complete tables in fresh, independent calls. A sender gives the exact path it would request to signal each value 0--15 on a shared file server where a request leaves a mark a later request can detect. A receiver gives the exact path it would check for each value. Neither sees the other's output, and neither is told the partner's model. We crossed two paraphrased wordings and two server contexts: a bare server (C0) and a package mirror that already holds \texttt{pkg-00.bin}--\texttt{pkg-15.bin} (C1). There were 24 calls per model, role, wording and context, 1,344 in all, at temperature 1.0 (Luna at its provider default). A pair is fully compatible when the receiver decodes all 16 sender paths correctly and unambiguously after a fixed normalisation. Every model reproduced an explicitly given convention exactly in every readiness call. Intervals come from a stratified two-way bootstrap over sender and receiver samples and treat the seven models as fixed.

\textbf{Results.} Both preregistered hypotheses hold for this model set: same-model pairs agree more than different-developer pairs, and paraphrasing the task barely changes the average (0.49 to 0.46). Pairing each sample once instead of crossing all samples gives the same picture (differences 0.16 and 0.14; post-hoc). The average hides two things. First, the advantage is model-specific. Treating each model as one unit (post-hoc), its own rate exceeds its mean rate with other developers for 6 of 7 models with the same wording (sign test $p=0.06$) and 4 of 7 with paraphrased wording ($p=0.5$). Luna, gpt-oss, Mistral and Qwen3 copies converge strongly; DeepSeek, Llama~4 and GLM~5 copies do not. Second, mixed pairs agree often. One in three different-developer pairs matched all 16 values, and 41\% did on the package mirror (0.41, 0.38--0.44). The environment supplies focal points: the bare number (\texttt{/7}) was the most common sender scheme for six of seven models on the bare server, and every mirror table from Luna, gpt-oss and Mistral used the existing file (\texttt{/generic-local/pkg-07.bin}), so Mistral senders and Luna receivers matched in every mirror pair. Our earlier exploratory count of 0/96 mixed-model matches, scored with a rule chosen after seeing the data, does not replicate.

\textbf{Implication.} A fleet should be assumed to share a usable code whether or not it mixes models. Mixing developers lowered average full agreement from about one half to one third and did nothing for pairs that share a focal point. Ponde et al.\ (2026, p.~5) already ran mixed Qwen/gpt-oss pairs that shared a supplied codebook. Our result adds that mixed pairs often agree on a code without one, so model diversity is not a general defense. Removing channels stays the primary control. A same-versus-mixed comparison changes capability, tokenisation and training as well as identity, so it does not isolate shared weights as the cause. Agreement alone transmits nothing: these tables were never run over a live channel.
